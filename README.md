# Автовокзал Дніпро — концепція СЕС, зарядної станції та накопичувача

Центральний автовокзал «Дніпро», вул. 128-ї Бригади Тероборони, 10.

- `3d/Автовокзал_Дніпро_3D.html` — 3D-модель (відкривається у браузері).
- `3d/template.html`, `3d/data.json` — шаблон сторінки і дані моделі.
- `дані/` — супутникові знімки, контури OpenStreetMap, `розрахунок_зон.txt`.
- `скрипти/gen3d.py` — будує геометрію, розкладку панелей, виробіток (PVGIS) і тінь.
- `панорами/` — програми знімання панорам; самі знімки і ключ у репозиторій не входять.

Стан на 26.11.2026 (панель ZNSHINE ZXN8-BD132-730, 730 Вт, 2384×1303 мм, поштучна розкладка): базовий сценарій 3 715 панелей / 2 713 кВт / 2 835 МВт·год на рік, максимальний 5 664 панелі / 4 135 кВт / 4 290 МВт·год.
Це концепція за супутниковим знімком: висоти, належність стоянок і несуча здатність дахів уточнюються.
